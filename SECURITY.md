# Security policy

## Reporting a vulnerability

Please report security vulnerabilities privately. Do not open a public issue or pull request for them.

- **GitHub private vulnerability reporting:** "Report a vulnerability" on this repository's Security tab
  (https://github.com/tirion-tools/libpgpsplit/security/advisories/new).
- **Email:** Arun@metope.ca, with "libpgpsplit security" in the subject.

Include the affected tag or commit, what an attacker gains, and an input or steps that reproduce it. Please give us a
reasonable time to release a fix before you disclose the issue publicly.

## Supported versions

Only the latest tag receives security fixes. Consumers pin a commit; update to the latest tag to get a fix.
